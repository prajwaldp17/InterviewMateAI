# 🤖 InterviewMate AI

**An AI-powered interview practice application built with Python, Streamlit, and Ollama.**

InterviewMate AI helps users practice interview questions, review their answers, and receive personalized feedback to improve their interview skills.

## ✨ Features

- 📝 **Interview Questions:** Practice questions from different categories, including HR, Python, and Customer Support.
- 🤖 **AI-Powered Feedback:** Get detailed feedback generated by a locally running language model.
- 📊 **Answer Evaluation:** Review word count, matched keywords, missing keywords, and answer scores.
- 💡 **Improvement Suggestions:** Identify areas where your answer could be clearer or more relevant.
- ✍️ **Sample Answers:** Learn from example answers and suggestions.
- 🔒 **Local AI Processing:** Uses Ollama to run the language model locally, without requiring a paid AI API.

## 🛠️ Tech Stack

- **Language:** Python
- **Frontend:** Streamlit
- **AI Integration:** Ollama
- **Language Model:** Llama 3.2 (1B)
- **Version Control:** Git and GitHub

## 🚀 Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/prajwaldp17/InterviewMateAI.git
cd InterviewMateAI
```

### 2. Create a virtual environment

```bash
python -m venv .venv
```

Activate it on Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

### 3. Install Python dependencies

```bash
python -m pip install -r requirements.txt
```

### 4. Install and start Ollama

Install Ollama from the official website:

https://ollama.com/download

Download the model:

```bash
ollama pull llama3.2:1b
```

Make sure Ollama is running on your computer.

### 5. Run the application

```bash
streamlit run app.py
```

Open the local URL displayed in your terminal, usually:

`http://localhost:8501`

## 💡 How It Works

1. Select an interview question from an available category.
2. Enter your answer in the application.
3. Review the initial evaluation and suggestions.
4. Request detailed AI-generated feedback.
5. Use the feedback to improve your answer and practice again.

## 🎯 Project Goal

The goal of InterviewMate AI is to make interview preparation more accessible by combining a simple web interface, automated answer evaluation, and locally running AI feedback.
